## 📝 What I Learned
- **CS1012 Error** — Used single quotes `' '` for strings; should be double quotes `" "`
- **CS0266 Error** — Assigned a number to a `char`; each type has specific rules
- Always use **double quotes** for text, **single quotes** only for 1 character
